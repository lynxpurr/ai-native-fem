# ANF 0.1.0a6

This research prerelease adds consistent-mass modal analysis for schema 1.4
planar trusses and frames, with mass-normalized modes, frequencies and versioned
modal result artifacts.

- **Modal model.** Schema 1.4 declares a planar structure with a positive
  material `density`, an empty `loads` object and
  `analysis: {"type": "modal", "modes": N}`. Static schemas 1.0–1.3 are
  unchanged.
- **Consistent mass.** `anf.dynamics.assemble_mass` assembles a dense global
  mass matrix. The truss uses the 4×4 local mass with axial and transverse
  translational inertia; the frame uses the Hermite 6×6 mass. Neither includes
  independent rotary inertia.
- **Modal solve.** `anf.dynamics.solve_modes` removes fixed DOFs and solves
  `K phi = lambda M phi` with the dense SciPy generalized eigensolver. It returns
  eigenvalues, rad/s, Hz, mass-normalized modes, DOF labels and residuals. A free
  planar model must have three rigid modes; a supported model must have none.
  Negative eigenvalues, rigid-mode mismatches and excessive residuals are
  rejected. A requested count beyond the available modes sets `truncated`; zero
  frequencies are never padded.
- **Artifacts.** `save_modal_result` and `load_modal_result` write and read
  `manifest.json` + `arrays.npz` with the model fingerprint, DOF labels, array
  digest and diagnostics. Changed digests, extra files, non-finite arrays and
  unsupported schemas are rejected.
- **Entry points.** `anf.application.run_modal` and the `anf.dynamics` Python
  interfaces. Modal analysis is Python-only; the CLI and MCP do not expose it.

## Limits

- Linear, small-displacement, planar `truss2d`/`frame2d` only. No plate mass,
  shear deformation, independent rotary inertia, 3D frames, shells, solids,
  laminates, damping, time integration, buckling or nonlinear analysis.
- Dense eigensolver within the existing 600-DOF planar cap. A sparse `eigsh`
  path and plate modal analysis are separate designs.
- Modal supports must be zero displacements. A nonzero support is rejected.
- The solver returns modes as a mass-normalized set. Mode signs are arbitrary
  and are normalized only for reproducible display; repeated frequencies are
  meaningful as a subspace.

## Compatibility and migration

- Schema 1.0–1.3 static models, results and the convenience beam/plate APIs are
  unchanged. No action is required for existing static users.
- Schema 1.4 is opt-in. A modal result manifest uses `modal-results-v1.4` and
  arrays are stored alongside it.
- Modal analysis requires the `sparse` extra (SciPy). The base installation
  still runs the static Python, CLI and MCP workflows; an explicit modal call
  without SciPy reports `backend_unavailable`.
- Modal results are not written by the static result APIs and are not exposed
  through the CLI or MCP.

## Verification

The suite runs on Linux Python 3.11/3.12 and Windows 3.12 for both the wheel and
source distribution. The base installation skips the sparse and modal tests; the
`sparse` extra runs them.

- Cantilever 16-element frequency errors against the Euler–Bernoulli closed
  form: `1.31e-7`, `5.11e-6` and `3.98e-5`; gate `1e-4`.
- Axial rod errors decrease from 8 to 16 elements and stay within `2e-2` at 16.
- A free planar frame has exactly three rigid modes; mass normalization and
  orthogonality meet the `1e-8` gate; elastic residuals meet `1e-9`.
- Node renumbering preserves frequencies, truncation never pads zero
  frequencies, and modal artifact tampering is rejected.
- With the test, MCP and sparse extras the suite has 466 tests; without SciPy it
  has 420 passing and 32 skipped (30 sparse tests and two skipped modal
  modules).

## Install

Download the wheel, source distribution and `SHA256SUMS` from the
[GitHub prerelease](https://github.com/lynxpurr/ai-native-fem/releases/tag/v0.1.0a6).
The source distribution includes the examples and schemas. Install the modal
extra from the directory containing the wheel:

```sh
python -m pip install "./ai_native_fem-0.1.0a6-py3-none-any.whl[sparse]"
```
