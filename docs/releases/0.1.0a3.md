# ANF 0.1.0a3

This research prerelease adds opt-in verification reports and an explicitly
selected MITC4 formulation for hard simply supported rectangular plates.

- Use `anf.verification.verify_cantilever` and `verify_plate` to obtain a
  schema 1.0 report with separate input, solve and verification statuses, a
  canonical input fingerprint, and named reference comparisons.
- To use MITC4, set `formulation="mitc4_rectangle"` and
  `support="hard_simply_supported"` when constructing a `Plate` for uniform
  pressure on an axis-aligned rectangle. Independent convergence results
  cover the documented rectangle, thickness and mesh ranges. Automatic
  MITC4 reports check the equilibrium residual and return
  `solved_unverified` after a successful solve.
- Existing `solve_cantilever` and `solve_plate` calls continue to return the
  original result objects. The default remains `q4_full`. The thin-plate
  Q4 example continues to demonstrate shear locking.

The assets are a universal wheel, a source distribution and `SHA256SUMS`.
Both package formats were tested on Linux with Python 3.11 and 3.12 and
on Windows with Python 3.12. NumPy is installed separately.
