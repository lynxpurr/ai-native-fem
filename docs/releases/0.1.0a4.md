# ANF 0.1.0a4

This research prerelease adds declarative static models and replayable
analysis records for the existing cantilever and rectangular plate solvers.

- **Python.** Validate a schema 1.0 model with explicit SI units, run the
  analysis and save the result as a JSON manifest and numeric NPZ arrays.
  The result records the normalized input fingerprint and separate solve
  and verification statuses.
- **Command line.** Use `anf validate`, `anf solve` and `anf inspect` to run
  the same model workflow. The `--json` option produces structured results
  and diagnostics for scripts.
- **Mesh convergence.** Run a study over explicit meshes and save a
  replayable JSON report, a Markdown summary, an SVG plot and per-mesh
  result bundles. The report retains failed reference comparisons and
  records which meshes ran.
- **Local MCP.** Install the optional `mcp` extra to run `anf-mcp` over
  stdio. A client can discover capabilities, validate and solve a model,
  run a convergence study and inspect a saved artifact. Calls return
  bounded summaries while full results stay in the configured workspace.

The beam solver covers linear Euler–Bernoulli cantilever bending in one
plane under a tip force, a uniform line load or both. The plate solver
covers linear Reissner–Mindlin bending on axis-aligned rectangles under
uniform pressure. The default `q4_full` supports clamped and hard simply
supported edges. Select `mitc4_rectangle` explicitly for hard simply
supported edges. The thin Q4 example retains the shear-locking case, where
the solve completes and the independent reference comparison reports
`verification_failed`.

Download the wheel, source distribution and `SHA256SUMS` from the
[GitHub prerelease](https://github.com/lynxpurr/ai-native-fem/releases/tag/v0.1.0a4).
The source distribution includes the examples and schemas. Follow the
[installation guide](https://github.com/lynxpurr/ai-native-fem/blob/v0.1.0a4/docs/mcp.md)
for base and MCP installs.
