# ANF 0.1.0a7

This research prerelease adds forced-dynamics analysis for schema 1.5 planar
trusses and frames: steady-state harmonic response and linear Newmark
transients, with versioned response artifacts.

- **Schema 1.5.** A planar structure with a positive material `density`, zero
  displacement supports and an analysis block of type `harmonic` or
  `transient`. Schemas 1.0–1.4 and their static, load-case and modal semantics
  are unchanged.
- **Damping.** Rayleigh damping only: `C = alpha * M + beta * K` with
  `alpha >= 0` in `s^-1` and `beta >= 0` in `s`. Modal damping ratios,
  non-proportional damping and complex modes are out of scope.
- **Harmonic solve.** `anf.dynamics.harmonic_response` solves
  `(K - w^2 M + i w C) U = F` directly at each declared frequency with a
  complex LU. A scaled condition metric separates numerically singular
  frequencies (`harmonic_singular`) from merely ill-conditioned ones, which are
  reported as `harmonic_ill_conditioned:<index>`. Convergence is checked with
  the backward error `||A U - F|| / (||A||_1 ||U|| + ||F||) <= 1e-12`.
  Frequencies are non-negative, strictly increasing and limited to 200 points;
  `f = 0` is the static limit.
- **Harmonic loads and results.** Nodal loads are complex amplitudes with a
  cosine phase; a bare number means zero phase. `HarmonicResult` carries the
  complex displacement on all DOFs, magnitudes, phases in degrees, per-frequency
  backward errors and condition estimates.
- **Transient solve.** `anf.dynamics.transient_response` integrates
  `M a + C v + K u = f` with the average-acceleration Newmark method
  (`gamma = 1/2`, `beta = 1/4`) on a uniform grid, using one Cholesky
  factorization of the effective stiffness and of the mass matrix. Initial
  displacement and velocity may be non-zero on free DOFs.
- **Transient loads.** Presets are evaluated on absolute time: `constant`,
  `ramp` (`t0_s` to `t1_s`) and `harmonic` (`amplitude * cos(2*pi*f*t + phase)`).
  The time grid is declared as `start_s`/`end_s`/`steps` or as an explicit
  uniformly spaced `times_s` array, up to 5000 steps and
  `n_dof * (steps + 1) <= 1_200_000`.
- **Transient results and failure semantics.** `TransientResult` stores the
  complete displacement, velocity and acceleration histories on all DOFs, the
  energy series `1/2 v'Mv + 1/2 u'Ku`, per-DOF peak displacement and time,
  global peaks, and the worst backward error with its step. Peaks and energy
  are computed from the same arrays. A non-finite state, a factorization failure
  or a step above the `1e-10` backward-error gate raises `NewmarkSolveError`
  with the step index and time; no partial result or artifact is produced. The
  gate also acts as a time-resolution check: though average acceleration is
  unconditionally stable, a step that is too coarse for the highest modes is
  rejected, so refine `dt` or coarsen the mesh.
- **Artifacts.** `save_harmonic_result` / `load_harmonic_result` and
  `save_transient_result` / `load_transient_result` write and read
  `manifest.json` + `arrays.npz` with the model fingerprint, DOF labels, array
  digest, shapes and diagnostics. The manifest schemas are
  `harmonic-results-v1.5` and `transient-results-v1.5`.
- **Entry points.** `anf.application.run_harmonic` and `run_transient`, plus the
  `anf.dynamics` Python interfaces. Forced dynamics is Python-only; the CLI and
  MCP do not expose it. The `docs/forced-response.md` guide and the
  `examples/dynamics/` declarations cover both analyses.

## Verification

The full suite passes on Linux Python 3.11/3.12 and Windows 3.12. The base
installation runs 449 tests with 60 skipped (30 sparse tests, two modal modules
and 28 forced-response solver tests); installing the `sparse` extra runs 523
tests.

Independent anchors measured with this implementation:

- SDOF harmonic amplitude and phase match the closed-form complex response to
  `1e-15`; the 16-element cantilever zero-frequency limit matches `FL^3/(3EI)`
  to `1e-12`; a 40-mode Euler–Bernoulli series agrees within `2e-5` up to twice
  the first frequency. Undamped exact resonance is rejected.
- Newmark step L2 errors are `1.141e-1`, `2.926e-2`, `7.357e-3`, `1.842e-3` and
  `4.606e-4` at `T/10` to `T/160`, with halving ratios `3.90`–`4.00`. Undamped
  energy drift stays below `1e-13` over 5000 steps, damped energy never
  increases, and a non-zero initial state matches its analytic decay to
  `6.5e-3`.

## Limits

- Linear, small-displacement, planar `truss2d`/`frame2d` only, within the
  existing 600-DOF cap. No plates, shells, 3D frames, shear deformation,
  laminates or nonlinear analysis.
- No support reactions or internal forces; a load on a fixed DOF is rejected
  rather than silently ignored.
- No response spectra or SRSS/CQC combination, no modal damping ratios, no base
  or multi-support excitation, no array or table force histories, no variable
  time steps and no nonlinear Newmark.
- The harmonic path factorizes every frequency directly; a modal-superposition
  sweep is a separate design. At the 597-free-DOF cap one complex factorization
  takes about 2 s on the reference machine, so a full 200-point sweep takes
  several minutes.

## Compatibility and migration

- Schema 1.0–1.4 models, results and the convenience beam/plate APIs are
  unchanged. No action is required for existing static or modal users.
- Schema 1.5 is opt-in. Forced dynamics requires the `sparse` extra (SciPy); the
  base installation keeps the static Python, CLI and MCP workflows, and a forced
  dynamics call without SciPy reports `backend_unavailable`.
- The two documentation commits correcting the `0.1.0a6` skipped-count erratum
  are included in this tree. The `v0.1.0a6` tag and its assets are unchanged.

## Install

Download `ai_native_fem-0.1.0a7-py3-none-any.whl` and `SHA256SUMS` from the
[GitHub prerelease](https://github.com/lynxpurr/ai-native-fem/releases/tag/v0.1.0a7),
verify the checksum, then install the extra that matches your workflow:

```sh
python -m pip install "./ai_native_fem-0.1.0a7-py3-none-any.whl[sparse]"
```
