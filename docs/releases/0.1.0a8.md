# ANF 0.1.0a8

This research prerelease adds linearized elastic buckling for schema 1.6
planar trusses and Euler frames with a declared nodal reference preload.

- **Preload.** `anf.stability.solve_preload` solves the linear static reference
  problem and recovers axial forces. Compression reduces the linearized
  stiffness through the axial-force geometric stiffness.
- **Buckling.** `anf.stability.solve_buckling` returns positive critical load
  factors, K-orthonormal modes and eigenpair residuals. Multiply the reference
  load vector by a critical factor to obtain the corresponding critical load.
  Invalid preload states and models with no positive factor raise a diagnostic
  error.
- **Validation.** Independent fixed-free, pinned-pinned and guided fixed-fixed
  Euler column anchors converge at fourth order. Rescaling the reference load
  preserves the physical critical load to a relative error of 1e-12. The
  measured preload and eigenpair residuals stay below 2.3e-14 and 5.1e-11,
  respectively. The installation matrix now runs the entire test suite after
  enabling `sparse`. See the [validation record](../validation.md).

## Scope and compatibility

Schemas 1.0–1.5 retain their existing behavior. Schema 1.6 is opt-in and uses
the Python interface with the `sparse` extra. The first implementation uses a
dense eigensolve with a 600-DOF cap. Its geometric stiffness represents axial
preload in planar trusses and frames. The calculation gives an elastic
bifurcation load. Nonlinear capacity, imperfections, post-buckling,
lateral-torsional and plate/shell buckling, end releases, result artifacts
and CLI/MCP entry points are outside this release's scope.

## Install

Download the wheel and SHA256SUMS from the
[GitHub prerelease](https://github.com/lynxpurr/ai-native-fem/releases/tag/v0.1.0a8).
Verify the checksum, then install the wheel in an active environment.

```sh
python -m pip install "./ai_native_fem-0.1.0a8-py3-none-any.whl[sparse]"
```

The [buckling guide](../buckling.md) shows how to run the cantilever and
pinned-column examples from the matching source distribution or tag.
