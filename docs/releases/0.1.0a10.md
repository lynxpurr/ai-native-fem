# ANF 0.1.0a10

This research prerelease adds `anf view` for saved transient displacement
histories. Each export creates a standalone HTML report that opens locally in
a browser.

- **Transient displacement history.** Schema 1.5 artifacts show the saved
  translation in metres or rotation in radians of one degree of freedom against
  absolute time in seconds. A marker shows the first sample at the absolute
  peak, and the readout keeps its original sign. A sample index retrieves any
  recorded sample and distinguishes repeated times. Opening a saved artifact
  works with the base installation.
- **Verification.** The viewer derives the DOF order and array sizes from the
  model before it loads any array, then checks the saved time grid and the
  saved displacement peaks against the history. An inconsistent time axis, DOF
  label order or peak is rejected before a report is written.
- **Compatibility.** The reader keeps the time grid saved by the solver,
  including a last sample that rounds away from the declared end time and
  repeated times at a large absolute offset. The base and sparse installation
  matrix runs the same checks on Linux and Windows.

## Install

Download the wheel and SHA256SUMS from the
[GitHub prerelease](https://github.com/lynxpurr/ai-native-fem/releases/tag/v0.1.0a10).
Verify the checksum and install the wheel in an active environment.

```sh
python -m pip install "./ai_native_fem-0.1.0a10-py3-none-any.whl"
```

Use the examples from the matching source distribution or tag. Choose fresh
output paths for each run.

## View a transient displacement history

To compute the example transient response before viewing it, install the
`sparse` extra.

```sh
python -m pip install "./ai_native_fem-0.1.0a10-py3-none-any.whl[sparse]"
```

```python
from pathlib import Path

from anf.application import run_transient
from anf.dynamics import save_transient_result

model = Path("examples/dynamics/transient-cantilever.json").read_bytes()
save_transient_result(run_transient(model), Path.cwd(), "transient-result")
```

```sh
anf view transient-result --output transient-history.html
```

Open `transient-history.html` and choose a node and degree of freedom.

The [viewer guide](../viewer.md) describes the read-only scope and display
conventions. Frequency response, batch results and buckling still require
separate artifact views.
