# ANF 0.1.0a5

This research prerelease adds linear planar structure analysis, named load
cases, an optional sparse solver, cantilever parameter studies and native mesh
input to the existing beam and plate workflow.

- **Planar structures.** Schema 1.1 declarations define nodes, `truss2d` and
  `frame2d` members, supports, and nodal or uniform transverse loads. The dense
  assembly returns displacements, reactions and local member-end actions. The
  bundled `structure.cantilever-tip.v1` reference checks the cantilever tip
  displacement and rotation, root force and moment.
- **Load cases and joints.** Schema 1.2 adds named cases, self-weight,
  linearly varying member loads and explicit linear combinations.
  `anf.recovery.member_forces` returns axial force, shear and moment at
  requested stations, and the batch envelope keeps the controlling case.
  Schema 1.3 adds frame end releases and rotational springs.
- **Sparse backend.** Install the `sparse` extra and pass
  `options.backend="scipy"` to use SciPy CSR/CSC assembly and SuperLU. The
  default remains dense. The CLI, MCP and schema 1.2/1.3 batch workflows stay
  dense. Model fingerprints, result schemas and verification semantics are the
  same across backends.
- **Parameter studies.** `anf.parameter_studies` scans explicit cantilever
  parameter grids or estimates local finite-difference sensitivity, with
  checkpoint/resume, retained failed samples and JSON/SVG reports.
- **Native meshes.** `anf.mesh_io` imports and validates native UTF-8 JSON mesh
  documents for planar members and uniform rectangular plates.
  `anf.meshing.generate_supported_mesh` generates lines and rectangles.
  External formats remain unsupported and are rejected explicitly.

## Limits

- The package remains linear static with small displacements. It does not
  include 3D frames, shear deformation, dynamics, buckling, nonlinear
  analysis, shells, solids, laminates or learned models.
- Planar structures cover the documented node, member, support and load forms
  within the declared size limits.
- Schema 1.2 and 1.3 batch runs are Python-only. The CLI and MCP accept schema
  1.0 and 1.1 single-solve declarations.
- Parameter studies target a schema 1.0 cantilever with a tip force.
- Native mesh input accepts planar-member and rectangular plate grids only.
  Gmsh, arbitrary quadrilaterals and curved shells remain unsupported.

## Compatibility

- Schema 1.0 models, schema 1.0 results, the convenience beam and plate
  functions, and the default `q4_full` fingerprint are unchanged.
- New schemas are opt-in, and each result schema matches its model schema.
  Existing a4 result directories remain readable.
- `anf inspect` reports `schema_version` and `ordering` for planar structure
  results.
- Install `ai-native-fem[sparse]` for the sparse path. Without it, an explicit
  sparse request reports `backend_unavailable` at `/options/backend`.
- The installed package now includes the `anf.elements` and `anf.backends`
  subpackages. The source distribution adds the new schemas, guides, examples
  and tests.

## Migration from 0.1.0a4

No action is required for schema 1.0 models or existing result directories.
Select the new schema by the feature: 1.1 for one planar load set, 1.2 for
named cases and combinations, and 1.3 for end releases or rotational springs.
`anf.model.validate_model` accepts 1.0/1.1;
`anf.model.validate_load_case_model` accepts 1.2/1.3;
`anf.application.run_load_cases` executes the batch. The CLI and MCP remain
single-solve. Install the `sparse` extra only when the SciPy backend is
wanted.

## Verification

The suite runs on Linux Python 3.11 and 3.12 and Windows Python 3.12 for both
the wheel and source distribution. Each installation runs without SciPy first
and then exercises the sparse extra.

- Planar statics are checked against closed-form axial, cantilever, simply
  supported beam and portal force-method anchors, including nonzero prescribed
  displacements and explicit mechanism failures.
- Sparse results match dense results within the documented tolerances and keep
  the `1e-8` free-DOF relative residual gate.
- Parameter sensitivities match the analytic cantilever derivatives within
  `5e-6` relative error, and failed or out-of-domain samples are retained.
- Native mesh round-trips preserve the physical model and input fingerprint.
  The rectangular MITC4 projection stays inside the existing 1% reference
  gate, and the thin Q4 locking case remains a failed comparison.

See the [validation record](https://github.com/lynxpurr/ai-native-fem/blob/v0.1.0a5/docs/validation.md)
and [methods](https://github.com/lynxpurr/ai-native-fem/blob/v0.1.0a5/docs/methods.md)
for the tested domain and error budgets.
