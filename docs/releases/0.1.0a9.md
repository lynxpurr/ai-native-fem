# ANF 0.1.0a9

This research prerelease adds `anf view` for saved static results and planar
mode shapes. Each export creates a standalone HTML report that opens locally
in a browser.

- **Static view.** Schema 1.0 beam and plate results and schema 1.1 planar
  structure results show the original and deformed mesh, saved scalar values,
  load and support locations, and the recorded solve and verification status.
- **Modal view.** Schema 1.4 artifacts show frequencies, eigenpair residuals,
  mass-normalized coefficients, rigid-body labels, and illustrative animation.
  Display amplitude uses a relative scale. Opening a saved artifact works
  with the base installation.
- **Compatibility.** The modal reader checks model-derived DOF order and
  array sizes before loading. It accepts the published a6 format, including
  empty mode selections and native float64 byte order. The base and sparse
  installation matrix checks the same published interfaces on Linux and Windows.

## Install

Download the wheel and SHA256SUMS from the
[GitHub prerelease](https://github.com/lynxpurr/ai-native-fem/releases/tag/v0.1.0a9).
Verify the checksum and install the wheel in an active environment.

```sh
python -m pip install "./ai_native_fem-0.1.0a9-py3-none-any.whl"
```

Use the examples from the matching source distribution or tag. Choose fresh
output paths for each run.

## View a static result

```sh
anf solve examples/models/cantilever.json --output beam-result
anf view beam-result --output beam.html
```

Open `beam.html` to select a field and deformation scale.

## View a saved mode shape

To compute the example modes before viewing them, install the `sparse` extra.

```sh
python -m pip install "./ai_native_fem-0.1.0a9-py3-none-any.whl[sparse]"
```

```python
from pathlib import Path

from anf.application import run_modal
from anf.dynamics import save_modal_result

model = Path("examples/structures/modal-cantilever.json").read_bytes()
save_modal_result(run_modal(model), Path.cwd(), "modal-result")
```

```sh
anf view modal-result --output mode-shapes.html
```

The [viewer guide](../viewer.md) describes the read-only scope and display
conventions. Frequency response, time histories, and buckling result views
remain separate capabilities.
